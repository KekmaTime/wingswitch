# WingSwitch

A lightweight Minecraft Fabric mod that allows you to quickly swap between an elytra and chestplate with a single keybind.

## Features

- Press the grave accent key (`) to instantly swap between your equipped elytra and any chestplate in your inventory
- Works with all vanilla chestplates (leather, chainmail, iron, gold, diamond, netherite)
- Compatible with all Minecraft 1.21.x versions
- Client-side only - works on any server or singleplayer

## Installation

1. Make sure you have Fabric installed. If not, get it from [fabricmc.net](https://fabricmc.net/use/)
2. Download the latest version of WingSwitch from the [Releases](https://github.com/KekmaTime/wingswitch/releases) page
3. Place the downloaded .jar file in your Minecraft `mods` folder
4. Launch Minecraft with the Fabric profile

## Configuration

The default keybind is the grave accent key (`), but you can change this in Minecraft's controls settings.
